Quick start

  1. Request a key: POST https://raen-mcp-gateway.fly.dev/keys/request with {"email":"you@example.com"} — verification link arrives by email, key valid 30 days.
  2. Point your MCP client at the gateway:
{
  "mcpServers": {
    "raen": {
      "url": "https://raen-mcp-gateway.fly.dev/mcp",
      "headers": { "Authorization": "Bearer YOUR_KEY" }
    }
  }
}

First call per wallet is free — charge-and-rebate on Base: you pay the challenge, RAEN instantly rebates the same USDC on-chain, net $0. Verified settlements: proof of commerce.
